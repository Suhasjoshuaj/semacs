#+title: semacs key cheat sheet
#+startup: overview

Open with =SPC c k= (or =C-c SPC c k=). =TAB= on a heading opens it, =S-TAB=
opens everything. =SPC s s= searches this file.

Every table names the command, so =M-x COMMAND= or =C-h f COMMAND= works too.
=C-h k= followed by any key tells you what it does in the buffer you are in.

* Notation
| Key     | Means                                                                |
|---------+----------------------------------------------------------------------|
| C-x     | hold Ctrl, press x                                                   |
| M-x     | hold Alt (Meta), press x                                             |
| S-x     | hold Shift                                                           |

| C-x 4 f | Ctrl+x, then 4, then f                                               |

| C-c SPC | the same leader from anywhere (insert state, terminals, Vim keys off) |

Terminal Emacs (=emacs -nw=) cannot send =C-;= =C-'= =C-,= =C-.= =C-`=: use
the =C-c= alternatives listed next to them.

** While typing in a terminal
Every key not listed here goes to the program, ESC included.
#+name: keys-in-terminal
| Key       | Command                     | Does                                              |
|-----------+-----------------------------+---------------------------------------------------|
| C-c ESC   | evil-force-normal-state     | Vim normal state: move, search, yank; i/a to type |
| C-x ESC   | suhas/normal-state          | same                                              |
| C-c SPC   | suhas/leader-map            | leader                                            |
| C-y       | ghostel-yank                | paste (your kill ring)                            |
| M-y       | ghostel-yank-pop            | replace paste with an older kill                  |
| C-c C-c   | ghostel-send-C-c            | Ctrl-C to the program                             |
| C-c C-z   | ghostel-send-C-z            | Ctrl-Z                                            |
| C-c C-d   | ghostel-send-C-d            | Ctrl-D                                            |
| C-c C-t   | ghostel-copy-mode           | frozen view to select/copy (q leaves)             |
| C-c C-q   | ghostel-send-next-key       | send the next key raw (e.g. C-c C-q C-x)          |
| C-c C-r   | evil-ghostel-toggle-send-escape | change where ESC goes in this terminal        |

- Click on the line you are typing: the cursor moves there.
- Drag with the mouse: selects and copies.
- Normal state: =p= =P= paste at the cursor, =u= undo, =dd= =dw= =cw= edit
  the current line. The shell edits one line at a time: =Up=/=Down= are
  history to it, so cursor moves never cross lines.
- Multi-line input: bash =C-. e=, Claude Code =Ctrl+G=: the text opens in a
  buffer. =C-c C-c= (or =:wq=) sends it back, =C-c C-k= aborts.
- Files a program opens with =$EDITOR= (=git commit= and the like) open in
  this Emacs, with the same =C-c C-c= / =C-c C-k=.

=C-M-h=, =M-a=, =M-q= know about functions and blocks).
